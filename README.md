One line, at most 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch — judged head to head by an AI judge.

Entry for the make.fun bounty
[Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

## Run it

```sh
node main.ts
```

Writes the breakup text to `/output/entry.txt`. Deterministic, standard library
only, no network, no API keys.
